# For Zuhaa ♡ — Pink Romantic Dream Website

A responsive, static surprise website made with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and words
- `style.css` — responsive styling and animations
- `script.js` — button interactions
- `images/` — add your own photos here

## Preview on your computer
1. Extract the ZIP file.
2. Open the `zuhaa-surprise-website` folder.
3. Double-click `index.html` to open it in a browser.

## Add your photos
1. Put three photos in the `images` folder.
2. Name them `photo-1.jpg`, `photo-2.jpg`, and `photo-3.jpg`.
3. To display them, replace the three `.photo-placeholder` blocks in `index.html` with image tags, for example:
   `<img src="images/photo-1.jpg" alt="A favourite memory">`
4. Add this CSS to `style.css`:
   `.gallery img { width:100%; height:300px; object-fit:cover; border-radius:16px; }`
   For the middle image, you can use a class such as `class="tall-photo"` and style its height to `360px`.

## Publish free with GitHub Pages
1. Sign in at https://github.com.
2. Click **New repository**.
3. Name it `zuhaa-surprise` and choose **Public**.
4. Create the repository.
5. Upload `index.html`, `style.css`, `script.js`, and the `images` folder contents (if you added photos). Keep all files in the repository root; do not upload the ZIP as the only file.
6. Open the repository's **Settings** tab.
7. Select **Pages** from the left menu.
8. Under **Build and deployment**, choose **Deploy from a branch**.
9. Choose branch **main** and folder **/(root)**, then click **Save**.
10. Wait a few minutes. GitHub will show the published address in Settings → Pages. It will look like:
    `https://YOUR-USERNAME.github.io/zuhaa-surprise/`

## Personalising it
- Change the sign-off `Sajeel` in `index.html` if needed.
- Edit the letter and the three reason cards to make the message sound like you.
- Use photos you have permission to share. Anyone with the public website link can view photos uploaded to a public repository.
- The music button is a placeholder by design; no music plays automatically. If you add audio, use a file you have permission to use and provide a visible play/pause control.

## Important
A public GitHub Pages website is visible to anyone who has its URL. Avoid uploading private photos, phone numbers, addresses, or other sensitive information.
